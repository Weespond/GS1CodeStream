# GS1CodeStream

Тестовый проект из двух приложений на C#/.NET: TCP-сервера и клиента для передачи синтетических кодов маркировки.

## Формат кода

Генератор создаёт человекочитаемую строку `(01)<GTIN-14>(21)<серийный номер>`. GTIN состоит из 13 случайных цифр и контрольной цифры; серийный номер — из 12 заглавных латинских букв и цифр. Это синтетическая имитация структуры GS1, а не реальные коды маркировки. Уникальность значений не гарантируется.

## Требования

.NET SDK 10.

## Запуск сервера

```sh
dotnet run --project src/GS1CodeStream.Server
```

Сервер слушает `127.0.0.1:5000` и обслуживает одного клиента одновременно. После подключения он отправляет по одному коду каждые 500 мс: UTF-8, один код на строку, разделитель — `\n`. При отключении клиента сервер ожидает нового подключения. Для остановки нажмите Ctrl+C.

Клиент не должен отправлять данные серверу. При получении хотя бы одного байта сервер закрывает соединение и ожидает следующего клиента. Закрытие клиентом своей стороны отправки также считается отключением.

Коды генерируются только при подключённом клиенте. Очередь и подтверждение доставки не предусмотрены: при разрыве соединения недоставленные данные не восстанавливаются.

## Запуск клиента

В отдельном терминале выполните из корня проекта:

```sh
dotnet run --project src/GS1CodeStream.Client
```

Клиент подключается к `127.0.0.1:5000` и добавляет полученные коды в `codes.txt` в текущей рабочей папке. Если сервер недоступен или соединение разорвано, клиент повторяет попытку через 2 секунды. Незавершённая строка при разрыве отбрасывается. Для остановки нажмите Ctrl+C. Ошибка файла завершает приложение.
