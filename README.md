# GS1CodeStream

Тестовый проект из двух приложений на C#/.NET: TCP-сервера и клиента для передачи синтетических кодов маркировки. Сейчас реализован генератор кодов; сетевой обмен будет добавлен позднее.

## Формат кода

Генератор создаёт человекочитаемую строку `(01)<GTIN-14>(21)<серийный номер>`. GTIN состоит из 13 случайных цифр и контрольной цифры; серийный номер — из 12 заглавных латинских букв и цифр. Это синтетическая имитация структуры GS1, а не реальные коды маркировки. Уникальность значений не гарантируется.

## Требования

.NET SDK 10.
